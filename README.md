# Final Foliage Reenabled

Source code of **Final Foliage Reenabled**, a mod for FINAL FANTASY VII REBIRTH (PC) that brings back foliage interaction:
- grass, flowers and bushes bend around characters;
- sword swings and spells push plants;
- plant wind reaches much farther;
- touching plants plays rustle sounds and small leaf bursts.

- How to build it: [BUILDING.md](BUILDING.md)
- Player instructions: [release/README.txt](release/README.txt)

This repository contains no game files. The shader pak is generated from your own copy of the game.

Made with the help of an AI coding assistant (Claude by Anthropic). The author directed, tested and tuned it.
